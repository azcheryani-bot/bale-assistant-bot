# Bale Assistant Bot

ربات دستیار هوش مصنوعی بله — همان نسخه‌ای که روی Hugging Face Space اجرا می‌شد،
بدون سرور Xray و بدون روتر تلگرام.

- `bale_assistant.py` — ربات بله (جمینی، اشتراک، پرداخت)
- اجرا با GitHub Actions: هر ۵ ساعت در دقیقه ۵۸ UTC ری‌استارت می‌شود
  (concurrency باعث می‌شود اجرای قبلی با شروع اجرای جدید متوقف شود).
- حافظه داخلی (RAM) و همگام‌سازی با دیتابیس قبل از توقف،
  دقیقاً مثل نسخه هاگینگ‌فیس در خود کد هست (`init_db` / `load_databases` /
  `flush_all_to_db` با `atexit` و هندلر `SIGTERM`).

توکن‌ها و آدرس دیتابیس در GitHub Actions Secrets ذخیره می‌شوند و در کد نیستند.
